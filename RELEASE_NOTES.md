**Caillou** — valeurs nutritionnelles pour 100 g, sans compte ni publicité.

- **Scanner un produit** : code-barres → fiche Open Food Facts (nutrition / 100 g, ingrédients, allergènes, Nutri-Score, NOVA, labels). Fonctionne hors ligne pour les produits déjà consultés.
- **Rechercher un aliment** : « brocoli », « pâtes », « pomme »… dans la table Ciqual 2025 de l'Anses (3 484 aliments, hors ligne), avec distinction cru / cuit.
- **Prendre une photo** : plusieurs aliments reconnus d'un coup, chacun avec ses valeurs / 100 g. À configurer dans Réglages (clé Mistral, proxy ou modèle local).

**Installer** : télécharger le fichier `.apk` ci-dessous sur un téléphone Android (7.0 ou plus), l'ouvrir et autoriser l'installation depuis cette source.

Données : Open Food Facts (ODbL, photos CC BY-SA) · Anses, table Ciqual 2025 (Licence Ouverte 2.0). Informations indicatives, pas un avis médical. Projet indépendant.
